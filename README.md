# Screen Journal

Особистий візуальний щоденник екрана для Windows, написаний на C++ (Win32 + GDI+).

Робить знімок усього робочого столу (з усіх моніторів) **раз на хвилину** і зберігає
кожен кадр як PNG у папку `Documents\ScreenJournal`. Працює тихо у фоні —
без вікна консолі, нічого не блимає на екрані.

Додатково:

- **Автозапуск при вході в систему** — вмикається/вимикається з меню в треї.
- **Години роботи** — знімки робляться лише в проміжки часу, вказані у файлі
  `hours.txt` (див. нижче).

## Для чого це

Інструмент для роботи на **власному** комп'ютері з відома власника: як допоміжний
журнал пам'яті («що я робив сьогодні»), запис процесу для подальшого перегляду,
або тихе логування власної активності.

## Важливо: це НЕ інструмент прихованого стеження

Програма спеціально зроблена так, щоб її **завжди можна було виявити й зупинити**:

- процес працює під власним ім'ям і **видимий у Диспетчері задач**;
- автозапуск використовує звичайний ключ реєстру `HKCU\...\Run`, тому його видно
  у **Диспетчері задач → Автозавантаження**;
- у системному треї є **значок з меню**: увімкнути автозапуск, змінити години,
  відкрити папку зі знімками, призупинити знімки, «Вихід»;
- знімки складаються у звичайну, легко доступну папку.

Вона не маскує процес, не ховається від Диспетчера задач і не заважає себе
закрити. Використовуйте її лише на пристроях, де ті, кого вона знімає, знають
про це. Приховане стеження за людьми без їхнього відома в багатьох країнах
незаконне.

## Збірка

Прапорець `/utf-8` для MSVC важливий — без нього український текст меню та
`hours.txt` буде зіпсовано.

**Visual Studio (Developer Command Prompt):**

```bat
cl /utf-8 /EHsc /O2 /DUNICODE /D_UNICODE screenjournal.cpp ^
   gdiplus.lib gdi32.lib user32.lib shell32.lib ole32.lib advapi32.lib ^
   /link /SUBSYSTEM:WINDOWS
```

**MinGW-w64:**

```bat
g++ -O2 -municode -mwindows screenjournal.cpp -o screenjournal.exe ^
    -lgdiplus -lgdi32 -luser32 -lshell32 -lole32 -ladvapi32
```

## Запуск

Запустіть `screenjournal.exe`. З'явиться значок у треї, а в
`Documents\ScreenJournal` автоматично з'явиться файл `hours.txt`.
Щоб зупинити — правий клік на значку в треї → «Вихід».

## Автозапуск при вході

Правий клік на значку в треї → **«Запускати при вході в систему»** (галочка
показує поточний стан). Далі програма стартуватиме автоматично щоразу, коли ви
входите у Windows. Вимкнути можна там само або в
**Диспетчері задач → Автозавантаження**.

## Години роботи (`hours.txt`)

Файл `Documents\ScreenJournal\hours.txt` задає проміжки часу, коли робити знімки.
Формат — по одному діапазону в рядку, 24-годинний час:

```
08:00-12:00
13:00-17:00
```

Правила:

- рядки, що починаються з `#`, ігноруються (коментарі);
- якщо файл **порожній** або без коректних діапазонів — знімки робляться **цілий день**;
- діапазон через північ теж працює, напр. `22:00-06:00`;
- зміни діють одразу — перезапускати програму не треба (файл перечитується
  перед кожним знімком).

Відкрити файл швидко можна з меню в треї → **«Змінити години (hours.txt)»**.

## Інші налаштування

У верхній частині `screenjournal.cpp` можна змінити:

- `kCaptureIntervalMs` — інтервал між знімками (за замовчуванням 60 секунд);
- `kFolderName` — ім'я папки для збереження;
- `kHoursFileName` — ім'я файлу з годинами роботи.
