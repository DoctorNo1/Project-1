# Screen Journal

Особистий візуальний щоденник екрана для Windows, написаний на C++ (Win32 + GDI+).

Робить знімок усього робочого столу (з усіх моніторів) **раз на хвилину** і зберігає
кожен кадр як PNG у папку `Documents\ScreenJournal`. Працює тихо у фоні —
без вікна консолі, нічого не блимає на екрані.

## Для чого це

Інструмент для роботи на **власному** комп'ютері з відома власника: як допоміжний
журнал пам'яті («що я робив сьогодні»), запис процесу для подальшого перегляду,
або тихе логування власної активності.

## Важливо: це НЕ інструмент прихованого стеження

Програма спеціально зроблена так, щоб її **завжди можна було виявити й зупинити**:

- процес працює під власним ім'ям і **видимий у Диспетчері задач**;
- у системному треї є **значок з меню**: «Відкрити папку зі знімками»,
  призупинити знімки, «Вихід»;
- знімки складаються у звичайну, легко доступну папку.

Вона не маскує процес, не ховається від Диспетчера задач і не заважає себе
закрити. Використовуйте її лише на пристроях, де ті, кого вона знімає, знають
про це. Приховане стеження за людьми без їхнього відома в багатьох країнах
незаконне.

## Збірка

**Visual Studio (Developer Command Prompt):**

```bat
cl /EHsc /O2 /DUNICODE /D_UNICODE screenjournal.cpp ^
   gdiplus.lib gdi32.lib user32.lib shell32.lib ole32.lib /link /SUBSYSTEM:WINDOWS
```

**MinGW-w64:**

```bat
g++ -O2 -municode -mwindows screenjournal.cpp -o screenjournal.exe ^
    -lgdiplus -lgdi32 -luser32 -lshell32 -lole32
```

## Запуск

Запустіть `screenjournal.exe`. З'явиться значок у треї. Знімки почнуть
зберігатися у `Documents\ScreenJournal` одразу і далі кожну хвилину.
Щоб зупинити — правий клік на значку в треї → «Вихід».

## Налаштування

У верхній частині `screenjournal.cpp` можна змінити:

- `kCaptureIntervalMs` — інтервал між знімками (за замовчуванням 60 секунд);
- `kFolderName` — ім'я папки для збереження.
